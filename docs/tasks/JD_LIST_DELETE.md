# 岗位 JD 列表删除（2026-10-10）

用户授权：截图中的岗位 JD 列表增加删除功能。本轮仅实现此项，完成后等待 Claude 独立验收。

## 实现

- 每条岗位右侧增加独立删除按钮，点击不会进入岗位详情。
- 复用 ConfirmDialog，显示岗位标题，明确告知岗位原文、解析结果及关联匹配报告、简历建议、模拟面试、Agent 分析将一并删除且无法恢复；简历及已保存版本保留。
- 复用既有 owned `DELETE /api/job-descriptions/:id`，没有修改后端数据删除规则。
- 请求期间禁止重复删除；成功立即移除列表项并重新读取列表，失败保留列表并显示错误。
- 桌面并排布局，手机沿用岗位卡片纵向信息排版；按钮有明确可访问名称、焦点及禁用状态。

# 报告版本与分析任务删除（2026-10-12）

用户要求截图中的报告历史版本和岗位分析任务都增加删除按钮。仅扩展这两处删除能力，不更改 AI 生成、知识校验或页面整体设计。

## 实现

- 报告版本和分析任务分别提供同行独立删除按钮、明确作用范围的确认弹窗、请求禁用与弹窗内失败信息；任务编号用于区分同简历/版本的多次任务。
- DELETE /api/match-reports/:id：仅所属用户可删；删除该版本及其关联建议、模拟面试和 Agent 分析；保留基础匹配、其他报告版本。
- DELETE /api/job-applications/:id：仅所属用户可删；删除该任务下的基础匹配、全部报告及上述关联产物，保留 JD/简历/版本快照。
- 保留最小 ID 墓碑，报告版本序号不回退，避免历史 ID 重用。已接受的建议作为已保存修改的来源保留；未接受建议不可继续应用。检索审计不删除。
- 检查同步 PENDING/RUNNING、队列中尚未启动的四类异步任务、反馈/Agent 步骤和建议应用锁，忙碌时 409 HISTORY_BUSY，写入前无部分删除。
- 所有报告读取/后续生成入口及任务/基础匹配读取拒绝已删除记录。删除当前项后清理路由中的历史指向并切换剩余项；删空后显示现有空状态。非当前项删除保留当前选择。

# 简历建议事实补充流程（2026-10-13）

用户要求完善截图中“需要补充真实信息”功能。本轮仅处理建议原因、核对问题、补充入口与生成时证据纠正，不扩展下一阶段。

## 实现

- 区分 AI 主动 FACT_REQUIRED 和服务端事实/证据校验失败。校验失败显示“证据待核对”，明确不一定缺少经历；拒绝、失效状态优先显示真实处理状态。
- 标题、求职意向、自我评价、工作、项目、技能与教育使用中文名称。新生成的主动事实建议包含至多四个具体 factQuestions；旧记录与校验降级记录按模块给出核对指引，不伪装成已经识别出的事实缺口。
- 保存 validationMessage，数值/技术实体与未支持的中文表述可查看具体原因。没有保存或展示不合格的 after/patch。
- 每条事实建议可展开锁定字段 before 与版本，支持打开本轮绑定 resumeId 的简历编辑器核对补充，以及复用已有 reject 接口暂不采纳。编辑保存沿用现有版本与自动保存链路。
- 版本说明集中展示：补充后需用最新版本创建岗位分析任务，再生成匹配、报告与建议；重生成原报告建议仍绑定旧版本。
- prompt v4 强调原文事实引用、仅措辞调整与求职意向不等于已有经历。证据错误与格式错误共用原有一次纠正预算，最多两次 Provider 请求。每次仍执行完整原路径、事实、引用与输入绑定校验，不放宽任何接受建议边界。
- 运行时存储支持 JSON/MySQL payload，无需新增 SQL 列。没有重写历史建议或个人简历。

# 简历版本历史删除（2026-10-12）

用户要求截图中的简历版本历史也增加删除功能。本轮仅实现该入口及其后端行为。

## 实现

- 每个版本独立删除按钮，复用 ConfirmDialog，明确删除范围、取消、请求禁用及弹窗内失败提示。
- DELETE /api/resumes/:resumeId/versions/:versionId 通过所属简历授权；跨用户、错配简历、重复删除与删除后详情返回 404。
- 版本历史采用 deletedAt 标记：history/versions 列表和版本详情不再提供已删除版本，新分析任务不能绑定它。已有分析内部仍可读取不可变快照，保留输入绑定、内容哈希和来源审计，当前简历内容/版本号不变。此操作并非彻底清除底层快照。
- 删除当前查看项后切换剩余版本，删空清除快照并展示空状态；同步清理新任务的版本选项。列表标题改为“简历版本历史”，说明内容只读、历史可删除。

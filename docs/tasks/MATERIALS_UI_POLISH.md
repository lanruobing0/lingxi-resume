# 面试资料页整理（2026-10-10）

用户提供个人资料空状态截图，指出前端布局混乱，授权整理当前页面。

## 调整

- 资料内容区限宽 1120px，统一个人/公共资料的标题、说明、搜索与工具栏；范围切换改为简洁的下划线选中态。
- 精简重复标题和长说明；新建、上传、刷新集中到工具栏。刷新使用有 accessible name/title 的图标按钮。
- 没有资料时不显示无意义的搜索输入；空状态限定在明确的浅色区域中，主要操作仅为上传第一份资料，并说明文件类型。新建仍为工具栏次级操作。
- 已有资料后显示搜索/上传；搜索无结果可清空。打开编辑表单时不再同时展示空状态。
- 公共资料页使用相同的标题/工具栏样式；手机搜索与操作分行，列表和表单保持单列。
- 浏览器发现个人表单缺少 `.knowledge-upload-picker` 的定位/布局规则，透明 file input 因 absolute inset 覆盖到表单外的按钮。补上个人表单作用域，使文件输入限定在拖放区，并整理内容确认复选框对齐。
- 使用现有 CSS/token/control，不新增依赖、不改变 backend 数据链、隐私确认、索引、隔离或业务接口。
